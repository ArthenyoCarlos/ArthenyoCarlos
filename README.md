## 🚀 Projetos em destaque

### 🛒 [Flash Sale Checkout](https://github.com/ArthenyoCarlos/flash-sale-checkout) · *em andamento*
Checkout de Black Friday com **100 unidades em estoque e milhares de compradores ao mesmo tempo**. O objetivo é não vender mais do que existe. Reproduzo o bug de *overselling* de propósito e resolvo etapa por etapa (locks no banco, Redis, fila), medindo cada solução com teste de carga.

`Java 25` `Spring Boot` `PostgreSQL` `Flyway` `Redis` `RabbitMQ` `Docker` `k6`

### 🧩 [Sudoku](https://github.com/ArthenyoCarlos/sudoku)
Sudoku jogável no terminal, em Java puro: gera um tabuleiro aleatório a cada partida, valida as regras de linha, coluna e bloco e permite desfazer jogadas. Projeto para praticar orientação a objetos.

`Java 21` `POO`
